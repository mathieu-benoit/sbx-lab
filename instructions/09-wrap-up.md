# Wrap up

You’ve completed the **Docker Sandboxes with GitHub Copilot Lab** lab!

✅ You now understand the key features of Docker Sandboxes:

- Protect your secrets and credentials from your agents.
- Enforce policies to control which egress endpoints, filesystem mounts and MCP server your agents can reach.
- Run a Docker Sandbox in direct mode or with multiple agents in parallel.
- Monitor your different Docker Sandboxes and their audit logs
- Use feature like Docker with the agent, do port forwarding, etc.
